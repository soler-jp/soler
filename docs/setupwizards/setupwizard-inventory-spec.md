# 在庫 SetupWizard 仕様

> このドキュメントは「何を・なぜ」を扱う仕様書である。
> 全体方針は [setupwizard-spec.md](setupwizard-spec.md) を参照。
> 実装の「どう作るか」は [setupwizard-design.md](setupwizard-design.md) を参照。

## 目的

仕入・在庫がある事業かを確認し、必要なら開始時点の棚卸資産を登録する。

あわせて、「年末に在庫確認が必要である」ことを利用者に伝える。

この SetupWizard は次を扱う。

- 仕入・在庫がある事業かの確認
- 期首の棚卸資産（`FiscalYear` / Opening Setup）
- 年末棚卸の必要性の周知

```text
期首の棚卸資産
  -> FiscalYear / Opening Setup

年末棚卸の必要性
  -> 周知のみ（この Wizard では記録を作らない）
```

---

## 位置づけ

- 初回 SetupWizard では質問しない
- 継続事業（`opening_context = carry_forward`）の Dashboard カードとして表示する
- Dashboard の優先度は「高」（数字に直接影響する）

---

## 表示条件

```text
opening_context = carry_forward
inventory_setup_status != completed
```

```text
在庫の扱いを確認しましょう
```

---

## 画面構成

1画面で完結する。在庫は他の Wizard と違って複数登録がなく、金額を1つ入力するだけなので、
確認・金額入力・年末棚卸の周知をすべて同じ画面にまとめる。

```text
1画面: 在庫の確認と期首在庫

  ・売るための商品や材料はありますか？（はい／いいえ）
  ・（はいの場合）この年のはじめに残っていた商品・材料の金額
  ・年末に在庫確認が必要であることの案内

  [保存]
```

### 銀行口座・現金・固定資産との違い

| 項目 | 他の Wizard | 在庫 |
| --- | --- | --- |
| 複数登録 | あり（行・カード） | なし（合計金額を1つ入力） |
| 管理対象（SubAccount / FixedAsset） | 登録する | 登録しない |
| 期首金額 | 登録する | 登録する（棚卸資産） |

在庫は個別品目を管理せず、金額ベースで扱う。個別品目管理は Wizard の対象外。

---

## 入力欄

### 仕入・在庫があるか

| 項目 | 必須 | 説明 |
| --- | --- | --- |
| 仕入・在庫があるか | 必須 | はい／いいえ（＝ `answer` の確定） |

```text
売るための商品や材料はありますか？

商品販売、制作販売、材料を使う仕事などの場合は「はい」を選んでください。
サービス業では、ほとんどないこともあります。
```

- ここで `answer(inventory)` を確定させる
- 「いいえ」の場合は `answer = no`, `status = not_needed` で終了

### この年のはじめの在庫（「はい」の場合のみ）

| 項目 | 必須 | 説明 |
| --- | --- | --- |
| この年のはじめの在庫金額 | 必須 | 期首棚卸高。円単位。なければ 0 |

#### 画面文言案（opening_context = first_year の場合）

```text
開業時点で、売るための商品や材料をすでに持っていた場合は、その金額を入力してください。
なければ 0 で構いません。
```

#### 画面文言案（opening_context = carry_forward の場合）

```text
前年の決算書の「期末商品（製品）棚卸高」を、この年のはじめの在庫金額として入力してください。
```

#### 「わからない」の扱い

金額欄に「わからない」は用意しない。

理由: 期首在庫は前年決算書の期末棚卸高、または開業時点の実地棚卸で確認できるため。

ただし、画面全体に対して「あとで登録する」は許す（`status = skipped`）。

### 年末棚卸の案内（入力なし）

同じ画面に、次の案内を表示する。

```text
仕入がある場合、年末に残っている商品や材料を在庫として確認します。
そのため、年の途中の差し引き額は、年末の在庫入力で変わることがあります。
```

- 入力は求めず、案内のみ
- 年末棚卸そのものは、決算フロー（または月次確認）で扱う。この Wizard では記録を作らない

---

## 完了条件

### status の遷移

| 状態 | 遷移条件 |
| --- | --- |
| `not_needed` | 「いいえ」を選び `answer = no` になった時点 |
| `pending` | `answer = yes` または `unknown` で、まだ「保存」していない |
| `completed` | 「はい」を選び、期首在庫金額を入力（0 を含む）して「保存」した |
| `skipped` | 「あとで登録する」を選んだ |

### completed の判定条件

- `answer(inventory) = yes`
- 当該 `FiscalYear` の期首棚卸高が入力されている（0 を含む）
- 利用者が「保存」を押した

---

## answer 遷移

- `unknown → yes`: Step 1 で「はい」を選択 → Step 2 へ
- `unknown → no`: Step 1 で「いいえ」を選択 → `status = not_needed`、カードを閉じる
- `yes → no`: Dashboard のカード操作から変更

---

## Opening Setup との連携

期首棚卸高は、Opening Setup の期首仕訳に組み込まれ、元入金の自動計算に反映される。

Wizard 内では元入金を明示しない。

---

## 扱わないもの

### 個別品目の在庫管理

商品ごとの数量・単価・SKU などの管理は、Wizard では扱わない。金額ベースの期首棚卸高のみを扱う。

### 棚卸資産の評価方法

最終仕入原価法・移動平均法などの評価方法の選択は、Wizard では扱わない。

### 年末棚卸そのもの

年末の実地棚卸と期末棚卸高の記録は、決算フローで扱う。この Wizard は周知のみ。

---

## 画面文言まとめ

| 会計用語（内部） | UI 表現 |
| --- | --- |
| 期首商品棚卸高 | この年のはじめに残っていた商品・材料の金額 |
| 期末商品棚卸高 | 年末に残っている商品や材料 |
| 棚卸資産 | 商品・材料 |
| 元入金 | （表示しない） |

---

## まとめ

在庫 SetupWizard は、次を1画面で完了させる。

```text
1. 仕入・在庫がある事業かを確認する
2. 期首の棚卸資産金額を入力する（FiscalYear / Opening Setup）
3. 年末棚卸が必要であることを周知する
```

他の Wizard と異なり、管理対象（SubAccount）は作らず、金額ベースで扱う。
