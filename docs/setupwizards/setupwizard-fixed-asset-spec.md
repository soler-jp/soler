# 固定資産 SetupWizard 仕様

> このドキュメントは「何を・なぜ」を扱う仕様書である。
> 全体方針は [setupwizard-spec.md](setupwizard-spec.md) を参照。
> 固定資産・減価償却モデルの設計は [fixed-asset-design.md](../fixed-asset-design.md) を参照。
> 実装の「どう作るか」は [setupwizard-design.md](setupwizard-design.md) を参照。

> **実装状況**: 固定資産 Todo / Handler は未実装。`fixed_asset_answer` の値は `initial_setup_data` に保存されるが、`GeneralBusinessInitializer` からは Todo が発行されない。以下は将来仕様として記述している。

## 目的

仕事で使う高額なものを登録し、当年度の減価償却見込みを作る。

この SetupWizard は次を扱う。

- 固定資産そのもの（`FixedAsset` への登録）
- 当年度の償却明細（`DepreciationService` による生成）
- 開始時点で存在する固定資産と Opening Setup の連携

SetupWizard は入力収集に専念し、台帳登録・償却計算は専用サービスに委ねる。

```text
入力収集
  -> 固定資産 SetupWizard

台帳登録・償却予定生成
  -> DepreciationService / FixedAsset

期首時点の帳簿価額
  -> FiscalYear / Opening Setup
```

---

## 位置づけ

- 初回 SetupWizard の質問3「固定資産」（key: `fixed_asset`）に対する Dashboard カードとして表示する
- Dashboard の優先度は「高」（数字に直接影響する）

---

## 表示条件

将来的に固定資産 Todo が実装された段階では、次を想定する。

```text
fixed_asset_answer = yes で生成された wizard_fixed_asset Todo が pending
```

### answer 別の見え方

#### answer = yes

Dashboard に次のカードとして並ぶ想定。

```text
固定資産を登録しましょう
```

#### answer = no

Todo を作らないため、Dashboard には表示されない。現行実装に `unknown` はない。

## 画面構成

1画面で完結する。複数の固定資産は「次へ」でページを分けず、同じ画面に資産カードを並べて一気に登録する。

固定資産は1件あたりの入力欄が多いため、行ではなく「資産ごとのカード」を積み上げる形にする。

```text
1画面: 固定資産の一覧入力

  ┌ 資産カード1 ──────────────────┐
  │ 名称 / 種類                     │
  │ 取得日 / 取得価額 / 初度登録日   │
  │ 事業使用割合                     │
  │ 前年までの償却状況（carry_forward）│
  │ → 今年の償却見込み額（自動表示）  │
  └──────────────────────────────┘
  ┌ 資産カード2 ──────────────────┐
  │ ...                             │
  └──────────────────────────────┘
  [＋ 固定資産を追加]

  [保存]
```

各カードが1つの固定資産に対応する。カードの追加・削除がその場でできる。
償却見込み額は、そのカードの入力が揃った時点で自動計算して表示する。

---

## 入力欄（各カード）

### 基本情報

| 項目 | 必須 | 説明 |
| --- | --- | --- |
| 名称 | 必須 | 例:「営業用の軽自動車」「作業用パソコン」 |
| 種類 | 必須 | 車（普通車／軽自動車）／パソコン／機械／設備／その他 |

「種類」は耐用年数・償却方法の自動決定に使う。

### 取得情報

| 項目 | 必須 | 説明 |
| --- | --- | --- |
| 取得日 | 必須 | いつ買ったか |
| 取得価額 | 必須 | いくらで買ったか（税込） |
| 初度登録日 | 車で中古の場合のみ必須 | 中古車の耐用年数計算に使う |

- 税込経理を前提とするため、取得価額は税込で受け取る
- 耐用年数・償却方法（`straight_line`）は種類から自動決定するため、利用者には聞かない
- 中古車は、購入日時点の初度登録日からの経過月数で耐用年数を簡便法により自動計算する

### 事業使用割合

| 項目 | 必須 | 説明 |
| --- | --- | --- |
| 事業使用割合 | 必須 | 0〜100%。私用と共用する場合に按分する。仕事専用なら 100% |

- 償却費のうち経費算入できる割合の計算に使う
- 家事按分の考え方だが、UI では「家事按分」という語を出さない

### 前年までの償却状況（carry_forward のカードのみ）

`opening_context = carry_forward` の場合のみ、カード内に表示する。

| 項目 | 必須 | 説明 |
| --- | --- | --- |
| 前年までの償却累計額 | 任意 | 前年の決算書の「減価償却累計額」または「未償却残高」から把握できる |

- `opening_context = first_year`（当年取得）の場合は、この欄を表示しない
- carry_forward の場合、期首時点の帳簿価額（未償却残高）が Opening Setup に反映される
- 入力を省略した場合の扱い（取得価額から経過年数で推定するか、未償却残高を直接聞くか）は design 側で確定する

### 今年の償却見込み額（自動表示）

利用者の入力に対して、各カード内に `DepreciationService` の試算結果を表示する。

```text
入力内容から、今年の経費になる見込みの金額を計算しました。
実際の金額は、年度末に確定します。
```

### 画面文言案（画面全体）

```text
車、パソコン、機械、設備など、長く使う高額なものを登録してください。
複数ある場合は、カードを追加してまとめて登録できます。
買った日と金額は、支払った消費税を含んだ総額で構いません。
```

## 完了条件

### Todo status の遷移（将来）

| status | 遷移条件 |
| --- | --- |
| `pending` | Todo が発行されてから、まだ Handler の実行が成功していない |
| `completed` | Handler が固定資産の登録と当年度償却明細生成に成功した |
| `dismissed` | 利用者が明示的にこの Todo を取りやめた |

### completed の判定条件（将来）

- 少なくとも1つの `FixedAsset` が登録されている
- 各固定資産に対して、当該 `FiscalYear` の償却明細（`DepreciationEntry`）が生成されている
- carry_forward の場合、期首帳簿価額が Opening Setup に反映されている

---

## answer 遷移

`fixed_asset_answer` は初回 SetupWizard の Step 4 で確定させ、`initial_setup_data` に固定される。現行実装に `unknown` はなく、初回完了後に回答を変える UI もまだ持たない。

## Opening Setup との連携

### first_year の場合

当年取得のため、取得は通常取引として記帳する。Opening Setup（期首）には影響しない。

### carry_forward の場合

期首時点の固定資産の帳簿価額（未償却残高）は、Opening Setup の期首仕訳に組み込まれ、元入金の自動計算に反映される。

Wizard 内では元入金を明示しない。

---

## 責務の分離

| 責務 | 担当 |
| --- | --- |
| 入力収集 | 固定資産 SetupWizard |
| 台帳登録・初回償却明細生成 | `DepreciationService` / `FixedAsset::registerFixedAsset()` |
| 償却予定スケジュール算出 | `DepreciationService` |
| 期首帳簿価額の反映 | Opening Setup |

SetupWizard は業務ロジックを持たず、収集した入力をサービスに渡すだけにする。

---

## 扱わないもの

### 少額減価償却資産・一括償却資産の特例

30万円未満の少額減価償却資産の即時償却や、一括償却資産の3年均等償却などの特例は、初版の Wizard では扱わない。

`straight_line` のみを初版の対象とする（[fixed-asset-design.md](../fixed-asset-design.md) の方針に従う）。

### 除却・売却

固定資産の除却・売却は、Wizard では扱わない。通常利用開始後の別フローで扱う。

### 定率法・その他の償却方法

初版は `straight_line` のみ。定率法は扱わない。

## まとめ

固定資産 SetupWizard は、次を1画面で完了させる。

```text
1. 何を使っているかをカードとして登録する（FixedAsset）
2. 取得情報から償却予定を自動生成し、見込み額をカードに表示する（DepreciationService）
3. carry_forward なら期首帳簿価額を Opening Setup に反映する
4. 複数ある場合はカードを追加してまとめて登録する
```

SetupWizard は入力収集に専念し、償却計算は `DepreciationService` に委ねる。
