# Soler オンボーディング設計

## 目的

このドキュメントは、Soler の初回オンボーディングにおける次の3つの設計をまとめる。

1. 個人事業主としての会計の説明
2. SetupWizard
3. Soler チュートリアル

それぞれの役割を分けることで、初心者に会計用語や設定項目を一度に押しつけず、段階的に理解できる構成にする。

---

# 全体構成

## オンボーディングの流れ

Soler の初回オンボーディングは、次の順番で進める。

```text
個人事業主としての会計の説明
  ↓
SetupWizard
  ↓
Soler チュートリアル
  ↓
通常利用開始
```

## 各段階の役割

| 段階 | 役割 |
| --- | --- |
| 個人事業主としての会計の説明 | 個人事業主がなぜ経理をするのかを理解する |
| SetupWizard | Soler を使い始めるための初期データを作成する |
| Soler チュートリアル | 作成済みの設定を使って、Soler でどう記録するかを理解する |

## 基本方針

- UI では会計用語を前面に出さない
- 借方・貸方・仕訳という言葉は初期オンボーディングでは出さない
- ユーザーにとって分かる言葉を先に出す
- 会計上の処理は内部で正しく行う
- SetupWizard では事業の初期設定だけに集中する
- Soler チュートリアルで、実際の入力方法を説明する
- 年度作成や年度締めという概念は、できるだけユーザーに操作させない

---

# 1. 個人事業主としての会計の説明

## 目的

個人事業主が、なぜ日々のお金の動きを記録する必要があるのかを理解する。

ここでは Soler の具体的な使い方や設定方法は扱わない。

扱うのは、個人事業主が事業のお金を記録し、最終的に決算書を作るために最低限知っておきたい考え方である。

## この段階で扱うこと

- 個人事業主は、1年分の事業の結果をまとめる必要があること
- 1年分の事業をまとめる作業を「決算」ということ
- 日々のお金の動きが、決算書を作るための材料になること
- 売上・仕入・経費の違い
- 経費は種類ごとに分ける必要があること
- 勘定科目という言葉の最小説明
- 仕事と私生活で共用している支払いの考え方
- 全額を経費にできない支払いがあること
- 仕事で使った分だけ経費にできること

## この段階で扱わないこと

- Soler の具体的な操作方法
- SetupWizard の入力項目
- 事業専用現金の登録
- 銀行口座の登録
- 固定費登録
- 取引相手登録
- 期首残高
- 源泉徴収
- 減価償却
- 棚卸の詳細
- 消費税の詳しい区分
- 事業主借
- 事業主貸
- 借方・貸方
- 仕訳
- 元帳
- 青色申告決算書の具体的な書き方
- 「分類が分からない場合はあとで整理できる」という Soler の機能説明

## ページ構成

| ページ | タイトル | 目的 |
| --- | --- | --- |
| Page 1 | 個人事業主は、1年分の事業をまとめます | 経理・決算・申告の関係を伝える |

| Page 3 | 経費は、種類ごとに分ける必要があります | 経費分類と勘定科目の最小説明をする |
| Page 4 | 全額を経費にできない支払いがあります | 仕事と私生活で共用する支払いの考え方を伝える |
| Page 5 | 次は、Solerを始める準備をします | SetupWizard へつなぐ |

## Page 1: 個人事業主は、1年分の事業をまとめます

### 目的

個人事業主は、事業の1年分の結果をまとめ、決算書を作る必要があると伝える。

また、日々のお金の記録が決算書の材料になることを伝える。

### 本文

個人事業主になると、1年分の事業の結果をまとめる必要があります。

売上はいくらか。  
仕入はいくらか。  
経費はいくらか。  
利益はいくらか。

これらを確認して決算書を作る作業を、「決算」といいます。

売上から、仕入と経費を引くと、事業の利益が分かります。  
利益をもとに税金を計算して申告します。

そのため、決算書を作るには、日々のお金の動きを記録しておく必要があります。

### ボタン

次へ

### このページで言わないこと

- 仕訳
- 借方・貸方
- 帳簿の種類
- 青色申告決算書の詳細
- 確定申告書の詳細
- Soler の操作方法

## Page 2: 事業のお金は、まず3つに分けます

### 目的

事業のお金の動きを、売上・仕入・経費の3つに分けて考えられるようにする。

### 本文

事業のお金の動きは、まず3つに分けて考えます。

**売上** は、仕事をして受け取るお金です。  
商品を売ったお金や、サービスを提供して受け取る報酬などが入ります。

**仕入** は、売るために買った商品や材料です。  
商品販売や制作販売をしている場合に出てきます。  
サービス業では、仕入がほとんどないこともあります。

**経費** は、事業を続けるために使ったお金です。  
スマホ代、交通費、仕事道具、広告費、打ち合わせ費用などが入ります。

まずは、記録するお金が「売上」「仕入」「経費」のどれに近いかを考えます。

### ボタン

次へ

### このページで言わないこと

- 収益
- 売上原価
- 販売費及び一般管理費
- 損益計算書
- 仕入と棚卸の詳しい関係

---

## Page 3: 経費は、種類ごとに分ける必要があります

### 目的

経費は全部まとめて記録するものではなく、種類ごとに分ける必要があると伝える。

ここで初めて「勘定科目」という言葉を最小限だけ出す。

### 本文

経費は、事業のために使ったお金です。

ただし、経費は全部まとめて「経費」として記録するのではなく、何に使ったお金なのかを種類ごとに分ける必要があります。

たとえば、

- スマホやインターネット代
- 電車やバスなどの移動費
- 仕事で使う道具や文房具
- 広告やチラシの費用
- 外部の人に仕事を頼んだ費用

このように、支払いの内容ごとに分けて記録します。

会計では、この分類の名前を「勘定科目」と呼びます。

### ボタン

次へ

### このページで言わないこと

- 勘定科目の一覧
- 補助科目
- 具体的な決算書の欄
- 「あとで分類できる」という Soler の機能説明
- 未分類経費
- Draft モデル

---

## Page 4: 全額を経費にできない支払いがあります

### 目的

仕事と私生活で共用している支払いは、全額を経費にできるわけではないと伝える。

「仕事で使った分だけ経費にできる」というルールを明確にする。

### 本文

個人事業主の場合、仕事と私生活で同じものを使うことがあります。

たとえば、

- 自宅の家賃
- 自宅の電気代
- スマホ代
- インターネット代
- 車の費用

このような支払いは、全額を経費にできるわけではありません。

仕事で使った分だけを、経費として計上できます。

たとえば、インターネット代の半分を仕事で使っている場合は、半分だけを経費として計上します。

車を仕事と私用の両方で使っている場合は、仕事で使った分だけを経費として計上します。

### ボタン

次へ

### このページで言わないこと

- 家事按分という専門用語
- 具体的な按分計算式
- 消費税への影響
- 「説明できることが大切」という抽象的な表現
- Soler の按分機能

## Page 5: 次は、Solerを始める準備をします

### 目的

個人事業主としての会計説明を締めて、SetupWizard へつなぐ。

### 本文

ここまでで、個人事業主の経理の基本を確認しました。

事業のお金は、まず売上・仕入・経費に分けて考えます。

経費は、何に使ったお金なのかを種類ごとに分ける必要があります。

仕事と私生活で共用している支払いは、仕事で使った分だけを経費として計上します。

次は、あなたの事業に合わせて、Solerを始める準備をします。

### ボタン

設定を始める

### このページで言わないこと

- 事業専用現金の登録
- 銀行口座の登録
- 固定費登録
- 取引相手登録
- Soler チュートリアルの内容

# 2. SetupWizard

## 目的

SetupWizard は、Soler を使い始めるために必要な初期データを作成する。

ここでは、経理の基礎説明や Soler の操作説明は行わない。

SetupWizard の役割は、利用者の言葉で入力された情報を、Soler の会計モデルに変換することである。

## 基本方針

- 会計用語を前面に出さない
- 利用者がすぐ分かる名前で設定する
- 事業主借・事業主貸は SetupWizard で聞かない
- 源泉徴収は SetupWizard で聞かない
- 詳細入力は初回 SetupWizard に詰め込まず、必要に応じて個別 SetupWizard へ分ける
- 過去データ全移行は扱わない
- 継続事業では、乗り換え年度の期首状態だけを作る
- 課税事業者か免税事業者かなど、初回利用に必要な判定だけを行う

## SetupWizard で作成する主なデータ

- `BusinessUnit`
- `FiscalYear`
- 初回導線で必要な標準 `Account` / `SubAccount`
- 初期状態に応じた期首データ
- 初回判定結果

実際の作成処理は `GeneralBusinessInitializer` に委譲する。

SetupWizard は、入力収集と initializer に渡すデータの組み立てに専念する。

## SetupWizard で聞かないもの

- 事業主借・事業主貸
- 源泉徴収
- 固定費の詳細登録
- 取引相手の詳細登録
- 固定資産の詳細登録

これらは、取引入力時・Soler チュートリアル・Dashboard 上の個別 SetupWizard で扱う。

---

## SetupWizard の全体フロー

```text
開始状態の確認
  ↓
事業名・開始年・税区分など初回利用に必要な情報を入力
  ↓
初期データ作成
  ↓
Dashboard で必要な個別 SetupWizard を案内
```

## 詳細仕様の置き場

SetupWizard の詳細な仕様・Step 定義・入力項目・文言・画面責務は、次のドキュメントで管理する。

- 何を・なぜ扱うか: [docs/setupwizards/setupwizard-spec.md](setupwizards/setupwizard-spec.md)
- どう実装するか: [docs/setupwizards/setupwizard-design.md](setupwizards/setupwizard-design.md)
- 個別 SetupWizard の仕様: [docs/setupwizards/](setupwizards/)

このドキュメントでは、オンボーディング全体における SetupWizard の位置づけだけを扱う。

# 3. Soler チュートリアル

## 目的

SetupWizard で作成した設定を使って、Soler で実際にどう記録するかを説明する。

この段階では、抽象的な会計説明ではなく、利用者自身の設定名を使った操作説明を行う。

たとえば、SetupWizard で次のように設定していれば、

```text
レジ現金
○○銀行 普通口座（1234）
```

Soler チュートリアルでは、その名前を使って説明する。

## 基本方針

- SetupWizard 後に表示する
- 作成済みの事業専用現金・銀行口座を使って説明する
- Soler の入力思想を説明する
- 「あとで分類できる」はここで扱う
- 個人のお金で払った場合はここで扱う
- 固定費はここで扱う
- 取引相手はここで扱う
- 固定資産の詳細登録はここから後続画面へ案内する

## この段階で扱うこと

- Solerでは「受け取った」「支払った」から記録すること
- 売上を受け取ったときの考え方
- 仕入を支払ったときの考え方
- 経費を支払ったときの考え方
- どこから払ったかを選ぶこと
- 個人のお金で払った場合の扱い
- 分類が分からない場合は、あとで整理できること
- 仕事と私生活で共用している支払いは、仕事分だけにできること
- 毎月・毎年の支払いは固定費として登録できること
- よく取引する相手を登録できること
- 固定資産がある場合は、詳細登録が必要なこと

## この段階で扱わないこと

- SetupWizard の初期データ作成
- 借方・貸方
- 仕訳の直接入力
- 決算書の詳細な作成手順
- 消費税の高度な設定

| Page 3 | 仕入を支払ったとき | 仕入と棚卸の入口を説明する |
| Page 4 | 経費を支払ったとき | 経費登録の入口を説明する |

## Page 1: Solerでは、受け取った・支払ったから記録します

### 目的

Soler では、会計用語からではなく、実際のお金の動きから記録することを伝える。

### 本文

Solerでは、難しい会計用語から始めません。

まずは、事業で起きたお金の動きを、

- 受け取った
- 支払った

から記録します。

そのうえで、売上・仕入・経費として整理していきます。

### ボタン

次へ

---

## Page 2: 売上を受け取ったとき

### 目的

売上登録の基本を説明する。

### 本文

仕事をしてお金を受け取ったときは、売上として記録します。

たとえば、

- 商品を売った
- サービスを提供した
- 請求した代金が入金された

といった場合です。

売上を記録するときは、

- いつ受け取ったか
- いくら受け取ったか
- どこに入金されたか
- 何の売上か

を入力します。

### 表示例

```text
入金先:
- レジ現金
- ○○銀行 普通口座（1234）
```

---

## Page 3: 仕入を支払ったとき

### 目的

仕入は経費とは別に扱うこと、年末の在庫確認で最終的な費用が変わることを説明する。

### 本文

売るための商品や材料を買ったときは、仕入として記録します。

仕入は、通常の経費とは少し扱いが違います。

年末にまだ売れずに残っている商品や材料は、在庫として確認します。

在庫として残した分は、今年の費用から外れます。

そのため、年の途中で表示される差し引き額は、年末の在庫入力で変わることがあります。

### 表示文言案

```text
売るための商品・材料を買った
→ 仕入として記録します
```

---

## Page 4: 経費を支払ったとき

### 目的

経費登録の基本を説明する。

### 本文

事業を続けるために使ったお金は、経費として記録します。

たとえば、

- スマホ代
- 交通費
- 仕事道具
- 広告費
- 打ち合わせ費用

などです。

経費を記録するときは、

- いつ支払ったか
- いくら支払ったか
- どこから支払ったか
- 何に使ったか

を入力します。

### 表示例

```text
支払元:
事業のお金
- レジ現金
- ○○銀行 普通口座（1234）
```

---

## Page 5: 個人のお金で払ったとき

### 目的

個人のお金で事業の支払いをした場合の扱いを、会計用語を使わず説明する。

### 本文

事業の支払いを、個人のお金で払うこともあります。

たとえば、

- 個人の財布から払った
- 個人の銀行口座から振り込んだ
- 個人のクレジットカードで払った

といった場合です。

この場合、事業用のお金の残高は減りません。

Solerでは、事業主が立て替えた支払いとして記録します。

### 表示例

```text
支払元:
個人のお金
- 個人の財布・現金
- 個人の銀行口座
- 個人のクレジットカード
- その他
```

### 設計方針

個人のお金は、`事業主借` の `SubAccount` としては作らない。

UI 上の支払元ラベルとして扱う。

会計上は `事業主借` に集約する。

---

## Page 6: 分類が分からないとき

### 目的

勘定科目がすぐに分からない場合でも、入力を止めなくてよいことを説明する。

### 本文

支払いを記録するとき、何の分類にすればよいか迷うことがあります。

Solerでは、分類が分からない場合でも、まず金額や内容を残しておけます。

あとで確認して、正しい分類に整理します。

ただし、決算書を作る前には、未整理のものを確認する必要があります。

### 表示文言案

```text
分類が分からない場合は、あとで整理できます。
決算前には、未整理の支払いを確認します。
```

### 設計方針

未分類のまま正式な経費として扱わない。

`ExpenseDraft` または `TransactionDraft` として保存し、分類確定後に正式な取引へ変換する。

---

## Page 7: 毎月・毎年の支払い

### 目的

固定費登録へ案内する。

### 本文

毎月・毎年くり返し発生する支払いは、固定費として登録できます。

たとえば、

- 電気代
- ガス代
- 水道代
- 家賃
- スマホ代
- インターネット代
- サーバー代
- 駐車場代
- 保険料
- 固定資産税
- 会計ソフト利用料
- サブスク利用料

などです。

固定費として登録しておくと、毎月の確認が楽になります。

### 設計方針

固定費は SetupWizard では聞かない。

Soler チュートリアル後、固定費登録画面でプリセットを表示して選ばせる。

---

## Page 8: よく取引する相手

### 目的

取引相手登録へ案内する。

### 本文

よく請求する相手や、よく支払いをする相手は、取引相手として登録できます。

登録しておくと、売上や支払いの入力が楽になります。

ここでは、まだ「売掛金」「買掛金」といった分類を決める必要はありません。

実際の取引を記録するときに、必要な形に整理します。

### 設計方針

取引相手は `Counterparty` として登録する。

いきなり売掛金・買掛金・売上高の `SubAccount` にはしない。

---

## Page 9: 高額な仕事道具や車がある場合

### 目的

固定資産登録へ案内する。

### 本文

高額な仕事道具や車、機械、設備などを事業で使っている場合は、固定資産として登録します。

固定資産は、買った年に全額を経費にするのではなく、何年かに分けて経費にすることがあります。

これを減価償却といいます。

Solerでは、固定資産を登録すると、今年の減価償却費の見込みを計算します。

### 設計方針

固定資産の詳細登録は SetupWizard では扱わない。

Soler チュートリアルまたは後続画面で、固定資産台帳として登録する。

## Page 10: 通常利用を始めます

### 目的

Soler チュートリアルを締めて、通常のダッシュボードへつなぐ。

### 本文

これで、Solerで記録を始める準備ができました。

まずは、日々のお金の動きを記録していきます。

売上を受け取ったら、売上として記録します。

売るための商品や材料を買ったら、仕入として記録します。

事業のために支払ったものは、経費として記録します。

年末には、記録した内容を確認して、決算書を作ります。

### ボタン

Solerを始める

# 4. 年サマリーと年度・決算状態のUI方針

## 目的

年のサマリー表示、通常の取引入力、決算状態が混乱しないようにする。

## 基本方針

- 年セレクターは、表示する年を切り替えるだけ
- 取引がどの年に入るかは、取引日で決める
- 決算状態は、年ごとのバッジで表示する
- 新しい会計年度を作る操作は、原則としてユーザーに出さない
- 前年の決算が未確定でも、翌年の入力はできる
- 決算確定済みの年を修正する場合だけ、明示的に解除する

## 年サマリーの構成

```text
‹ 2025年　2026年　2027年 ›
1月1日〜12月31日　［記録中］

売上　仕入　経費　今の差し引き
```

## 決算状態

| 内部状態 | ユーザー表示 |
| --- | --- |
| `open` | 記録中 |
| `closing` | 決算を確認中 |
| `closed` | 決算確定済み |

## 状態別の表示文言

### 記録中

```text
2026年分を記録しています。
決算は、年末の取引を入力してから行います。
```

### 決算を確認中

```text
2026年分の決算を確認しています。
不足している記録や、年末の在庫などを確認してください。
```

### 決算確定済み

```text
2026年分の決算は確定済みです。
修正する場合は、決算を修正できる状態に戻します。
```

## 年の途中の差し引き表示

年の途中では、正式な利益ではなく「今の差し引き」として表示する。

```text
今の差し引き
売上から、記録済みの仕入・経費と、今年の減価償却費の見込みを引いた金額です。
年末の在庫入力や固定資産の確認で、最終的な利益は変わることがあります。
```

## 仕入がある場合の補足

```text
仕入がある場合、年末に残っている商品・材料を在庫として入力します。
そのため、この金額は年末に変わることがあります。
```

## 固定資産が未登録の場合の補足

```text
固定資産の登録がまだ終わっていません。
車・パソコン・機械などを使っている場合、減価償却費を登録すると差し引き額が変わることがあります。
```

## 新しい年の扱い

ユーザーに「新しい会計年度を作る」とは表示しない。

2027年1月の取引を初めて登録したときに、内部で2027年分の `FiscalYear` を作成する。

画面では次のように表示する。

```text
2027年分の記録を始めました。
2026年分の決算が確定すると、開始時点の金額が自動で引き継がれます。
```

## 前年未確定の翌年表示

```text
2027年分を記録しています。
2026年分の決算はまだ確定していません。
現金や銀行口座などの開始金額は、前年の決算後に確定します。
```

# 5. 最終的な切り分け

## 個人事業主としての会計の説明で扱うもの

- 個人事業主は年に一度、決算すること
- 決算書を作るために日々のお金を記録すること
- 売上・仕入・経費
- 経費は種類ごとに分ける必要があること
- 勘定科目という言葉の最小説明
- 共用支払いは仕事で使った分だけ経費にできること

## SetupWizard で扱うもの

- 新規開業か継続事業か
- 事業名
- 開始年
- 消費税の申告が必要か
- 事業専用現金
- 事業で使う銀行口座
- 開始時点の残高
- 継続事業の場合、前年の青色申告決算書から期首状態を作ること

## Soler チュートリアルで扱うもの

- 受け取った・支払ったから記録すること
- 売上登録
- 仕入登録
- 経費登録
- 個人のお金で払った場合
- 分類が分からない場合
- 固定費登録
- 取引相手登録
- 固定資産登録

## 通常画面で扱うもの

- 年サマリー
- 年ごとの記録状態
- 決算確認
- 決算確定
- 年末在庫確認
- 固定資産確認
- 次年への開始金額の引き継ぎ
